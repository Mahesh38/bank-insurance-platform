## Figma

**Status: 🔴 empty — no exports have been captured.**

The client-review prototype is **login-gated**, so frames cannot be pulled without a
walkthrough or a manual export from someone with access. This is tracked as **D-012** in the
[DECISION-LOG](../DECISION-LOG.md); until it is closed, treat Figma as **reference only** —
it is the lowest-priority input in the
[document win-order](../README.md#document-win-order-when-docs-disagree).

When exports become available, create `figma/`, drop the PNG/PDF frames in, then register
inventory progress in [05-figma-and-artefact-intake.md §1](../05-figma-and-artefact-intake.md)
and map screens in [04-process-and-journey-canvas.md §4](../04-process-and-journey-canvas.md).
