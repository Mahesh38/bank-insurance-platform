## 2. Purpose

The Product Details page enables the seller to understand one selected Savings product and its plan options before proceeding to the Detailed Quote page. The seller may review and edit quote inputs, understand benefits and product working, read general eligibility and exclusions, view riders, download or share the product brochure, generate and share a customer-specific Benefit Illustration, review approved objection-handling content, and select Buy Now from any Product Details tab.

## 3. Business Objectives

- Provide a complete yet easy-to-understand view of the selected Savings product.
- Keep all product, benefit, eligibility, exclusion and content sections API driven.
- Differentiate Participating and Non-Participating Savings plans correctly.
- Allow the seller to revise quote inputs for the same product without editing Suitability.
- Maintain consistent quote values across Listing, Compare Plans, Product Details and Detailed Quote.
- Support secure download and sharing of brochures and customer-specific Benefit Illustrations.
- Allow Buy Now from Overview, Coverage and RM Toolkit using the latest valid quote configuration.

## 15. Persistent Buy Now

- Buy Now shall remain available on Overview, Coverage and RM Toolkit.
- Enable only when product/plan is active, mandatory inputs are valid and a latest successful quote exists.
- Disable while quote or plan-option refresh is pending or failed.
- On click, validate current quote version and save insurer, product, plan option, product version, quote inputs, participation type, illustration rate and product source.
- Pass Lead ID, Suitability Assessment ID, mapping version and latest quote reference to Detailed Quote.
- Do not generate final BI, select riders, change stage, send communication or lock Suitability by Buy Now alone.
- Prevent duplicate handoff requests.

## 23. Key Business Rules Summary

KBR-01: View Details does not select the product for purchase.

KBR-02: Product Details has Overview, Coverage and RM Toolkit tabs.

KBR-03: Quote inputs and plan option are editable and changes refresh the full page.

KBR-04: Sort By is not present on Product Details.

KBR-05: Non-Participating plans display guaranteed values and no 4%/8% toggle.

KBR-06: Participating plans display 8% by default and allow 4%; illustrated values are non-guaranteed.

KBR-07: All product benefits, timelines, returns, eligibility, content, coverage and exclusions are API driven.

KBR-08: Claim Settlement Ratio and Active Policies are insurer-level informational metrics.

KBR-09: Premium Breakup is consolidated and shown once.

KBR-10: Riders are informational only; selection occurs on Detailed Quote.

KBR-11: Plan Brochure is common across variants and shareable through Email, SMS and WhatsApp.

KBR-12: Customer-specific BI can be generated and shared through Email, SMS and WhatsApp.

KBR-13: Successful customer-specific BI generation triggers Eligible Lead, Quote Generated, Suitability lock and reassignment block.

KBR-14: Multiple BIs are retained as versions under the same Lead ID.

KBR-15: Customer objections use a one-open-at-a-time accordion.

KBR-16: Create Pitch Deck is separate; Top 5 Prospects is excluded.

KBR-17: Buy Now is persistent on all tabs and opens Detailed Quote using the latest valid quote.

KBR-18: Back restores Listing or Compare state.

KBR-19: All quote values across sections must use a consistent quote reference.

KBR-20: All material user and API events are audited.
