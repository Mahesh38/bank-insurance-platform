# M5.2 — Operator runbook (orphan import)

**Status:** Mechanism ready. **First push is not authorised** until the signed
gates exist. This file is the sequence a bank operator runs on a company machine.
**Owner:** Shivanshi (SRE). **Does not replace** Board 6 / Board 4 signatures.

An agent must not write `evidence/C-SEC-1.signed`, `evidence/C-CMP-1.signed`, or
`evidence/finding-B.resolved`.

## What “done” looks like

Three **empty** GitLab projects (created in M4.3) each receive **one** company-authored
root commit, subject `Initial commit`. `identity-guard.py` is clean. Source history
is an offline `git bundle` (`AC-8`), never a GitLab remote.

## Sequence

On a **company** machine, full (non-shallow) clone of the source, dedicated
automation token for fetch of empty projects only:

```bash
export SRC=/path/to/full-clone
export EVIDENCE_DIR=/path/to/evidence          # the three signed files
export COMPANY_GIT_NAME="Platform Engineer"
export COMPANY_GIT_EMAIL="dev@au.bank.in"      # real bank mailbox
export COMPANY_EMAIL_DOMAIN="au.bank.in"

# 1. Gate check — no copy, no push
PREFLIGHT=1 \
  GITLAB_FRONTEND_URL=git@gitlab-ce.au.bank.in:insurance/bank-insurance/product/frontend.git \
  GITLAB_BACKEND_URL=git@gitlab-ce.au.bank.in:insurance/bank-insurance/product/backend.git \
  GITLAB_GOVERNANCE_URL=git@gitlab-ce.au.bank.in:insurance/bank-insurance/governance/platform-governance.git \
  bash gitlab-bootstrap/scripts/migrate-repositories.sh

# 2. Inspect rehearsal orphans if you want a local preview
OUT=/tmp/m52-rehearse REHEARSE=1 \
  bash gitlab-bootstrap/scripts/migrate-repositories.sh
# expect: 1 commit, no parents, subject Initial commit, identity-guard clean
# CLAUDE.md / .claude / m2-evidence / .github absent from platform-governance

# 3. Seal the source graph offline (AC-8) — not a GitLab remote
OUT=/tmp/m52-import \
  SEALED=/secure/offline/pre-gitlab-migration.bundle \
  PUSH=1 \
  GITLAB_FRONTEND_URL=... \
  GITLAB_BACKEND_URL=... \
  GITLAB_GOVERNANCE_URL=... \
  bash gitlab-bootstrap/scripts/migrate-repositories.sh
```

`PUSH=1` refuses if any destination already has refs. That is the day-0 control.
`REHEARSE=1` cannot set `PUSH=1`. `PREFLIGHT=1` cannot set `PUSH=1`.
`PREFLIGHT=1` cannot combine with `REHEARSE=1` — that pair would skip the signed gates.

## After push (M5.10)

On each receiving project:

```text
rev-list --count HEAD          = 1
rev-list --max-parents=0 HEAD  = HEAD
log -1 --format=%s             = Initial commit
author / committer             = COMPANY_GIT_*
identity-guard.py --tree/--git = clean
```

History or a personal-forge / AI author is a **failure**, not a polish item.

## What this environment cannot do

The authoring agent cannot reach `gitlab-ce.au.bank.in`, cannot hold a bank
`GITLAB_TOKEN`, and cannot manufacture the three signed files. Preflight from
this workspace is expected to **STOP** on those files until humans write them.
